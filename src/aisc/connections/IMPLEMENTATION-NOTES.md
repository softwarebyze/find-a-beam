# Bolt, weld, group and element engine

Engine units are kip, in., ksi. Existing exports and signatures in bolts.ts, welds.ts, groups.ts and elements.ts remain intact. The shared index/types files were not edited.

- Strength results carry per-state factors, citations, and quantities. Use `available(result, method)`.
- `analyzeBoltGroup` and `analyzeWeldGroup` (direct exports from groups.ts) add centroid, element forces, and equilibrium residual to the shared group result. Force coordinates and IC coordinates are relative to the centroid. The angle runs from downward vertical toward +x. Positive eccentricity offsets the load toward `(cos(angle), sin(angle))`; applied moment is `-eP`.
- Bolt IC coefficients use the unmodified Manual empirical law `(1-exp(-10Δ))^0.55`, Δmax = 0.34 in. At that deformation the empirical response is 0.9815 of its asymptote. Exactly concentric bolt groups use C = n; small nonzero eccentricity retains this approximately 1.85% empirical reduction. No upward normalization is applied.
- Weld IC uses angle-dependent Δm and Δu, compatibility, and midpoint integration (120 subdivisions per longest segment by default). The response is capped at its nominal peak. `analyzeWeldGroup(input, refinement)` exposes refinement for convergence checks. The elastic method omits directional enhancement.
- Weld coefficient convention is **nominal**: `Rn = C (FEXX/70) D l`, with D in sixteenths and l the longest input segment. Apply phi = 0.75 or Omega = 2. This is explicit in the returned steps and page; it is not a pre-factored Manual table coefficient. Geometry presets have explicit coordinates rather than claiming a particular table's datum or a-definition.
- `minimumBaseMetalThickness(D, Fu, weldLines, shearPlanes)` distinguishes weld lines from resisting shear planes: one E70 line / one plane is 3.09D/Fu; two lines / one plane is 6.19D/Fu. `minimumBaseMetalThicknessForTwoWeldLines(D, Fu, resistingSides)` supplies the requested 6.19 (one resisting side) / 3.09 (two resisting sides) convention. These are rupture-matching checks; yielding and directional effects remain separate.
- `elementBoltedSpliceTensionRupture` and `boltedSpliceEffectiveArea` explicitly apply the 0.85Ag splice-plate cap. Generic `elementTensionRupture` accepts the actual effective net area, including for welded elements.
- J4.4 above KL/r = 25 evaluates E3 flexural buckling of a nonslender effective section. Other Chapter E modes need section geometry and are identified in warnings.
- Bolt bearing uses one ply and one clear distance; eccentric-group capacity conservatively uses the same least bolt/ply strength throughout. Direction-specific clear distances, nonuniform strengths, prying, and slip under applied tension require separate evaluation. Single-bolt warnings identify long-joint / long-grip effects whose geometry is absent from the contract.

Validation uses the confident 3/4-in. Group 120-N bolt value (17.9 kip LRFD), the E70 weld-per-inch coefficients, independent Chapter J arithmetic, force/moment equilibrium, symmetry, and discretization convergence. No unverified eccentric Manual table coefficients were used.

Specification: [ANSI/AISC 360-22](https://www.aisc.org/globalassets/product-files-not-searched/publications/standards/a360-22w.pdf), §§J2–J5 and Tables J3.1–J3.4. Weld deformation background: [AISC Connections in Steel Structures VI](https://www.aisc.org/globalassets/aisc/manual/15th-ed-ref-list/connections-in-steel-structures-vi.pdf) (Lesik–Kennedy relationships). Inch-bolt tables remain inch-bolt tables when displayed in SI.
